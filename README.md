# 수능실감 500제 성과 대시보드

회차 결과를 입력·수정·삭제하고 정확도, 시간효율, 종합 성장지수, 객관 난이도, 난도 보정 성취, 병목 및 21~40회 목표를 자동 계산하는 설치형 웹앱입니다.

## GitHub Pages 배포
1. 이 압축파일의 내용 전체를 GitHub 저장소의 `main` 브랜치에 올립니다.
2. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
3. Actions의 배포가 끝나면 `https://사용자명.github.io/저장소명/` 주소로 접속합니다.

## iPad 홈 화면 설치
1. 배포된 주소를 Safari에서 엽니다.
2. 공유 버튼을 누릅니다.
3. **홈 화면에 추가**를 선택합니다.

## 데이터 저장
데이터는 브라우저의 localStorage에 저장됩니다. 웹앱의 **백업·설정 → JSON 백업**을 정기적으로 사용하세요. 같은 주소라도 다른 브라우저·기기에서는 자동 동기화되지 않습니다.
