# 영어 500제 성과 대시보드 PWA v1.2

개선 사항
- iPad 화면에서 글자 겹침과 칸 겹침을 줄이도록 레이아웃 재설계
- 회차 선택 시 제한시간·객관 난이도·3점 문항 기본값 자동 입력
- 오답 번호를 탭 버튼으로 빠르게 선택
- 입력 폼을 필수 입력 / 선택 입력으로 단순화
- 회차별 난이도 기본값 1~50회 내장

업데이트 방법
1. 기존 GitHub 저장소에서 `index.html`, `manifest.webmanifest`, `sw.js`, `404.html`을 새 버전으로 교체합니다.
2. 캐시 갱신을 위해 홈 화면 앱을 완전히 종료 후 다시 실행하거나 Safari에서 한번 새로고침합니다.
